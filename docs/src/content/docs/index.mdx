## What it looks like

A theme, a typed config and a command — the whole plugin.

```kotlin
class MyPlugin : SculkPlugin() {
    // Messages are written against meaning, not colour: changing what "value" looks like is one
    // edit here rather than a search for every coloured string.
    override val theme = SculkTheme(
        mapOf("value" to ThemeStyle.Gradient(listOf("#8be9fd", "#50fa7b"))),
    )

    override fun setup() {
        val settings = sculk.config.load<Settings>().getOrThrow()

        // command { } builds the command; the leading + registers it with the plugin.
        +command("gifts") {
            description = "Says how many gifts a player gets."
            executes {
                // count goes in as a value, never substituted into the template.
                reply("<value><count></value> per player.", "count" to settings.giftAmount.toString())
            }
        }
    }
}
```
