# Workstream B — Paper API capability map, Minecraft 1.21 → 26.3

Date: 2026-10-12. Scope: Paper only (Folia depth = workstream C, Velocity = workstream D).
Purpose: feed the Sculk 6 capability engine (Native / Emulated / Degraded / Unavailable) with
verified first-version data instead of scattered version checks.

Evidence base (all reproducible, see §5):
- Fill v3 API build lists for every 1.21+ version (`https://fill.papermc.io/v3/projects/paper/versions/<v>/builds`).
- `repo.papermc.io` `maven-metadata.xml` + six downloaded `paper-api` jars (1.21, 1.21.4, 1.21.11, 26.1.2, 26.2, 26.3) plus three 26.2 bisect jars, scanned with `javap`/zip for class presence and `ApiStatus` markers.
- papermc.io news posts, docs.papermc.io, jd.papermc.io, minecraft.wiki.

Legend: **Y** = present in that anchor jar · **.** = absent · **E** = `@ApiStatus.Experimental` marker present in the class file · UNVERIFIED = stated by a secondary source or inferred, not checked against a primary source.

Notes:
- Correction to the brief: Paper 26.3 is **no longer pre-stable** — build 175 was promoted to STABLE on 2026-10-11 ("Promote build channel to stable"). Builds 3–49 were alpha, 134–174 beta.
- Paper never shipped 1.21.2 or 26.1/26.1.0; 1.21.5, 1.21.9 and 26.1.1 never got a stable build. Treat those as not-a-target.
- Release-channel names changed in 1.21.7: `experimental`→`alpha`, new `beta`, `default`→`stable` (https://papermc.io/news/1-21-7).
- Paper main branch today = 26.3; `ver/26.2`, `ver/26.1.2`, `ver/1.21.11`, `ver/1.21.10`… exist for backports (`git ls-remote` 2026-10-12). Backports do land on stable lines (e.g. experimental-annotation removal landed in 26.2 b100, removal-reason API in 26.2 b109), so "first version" ≠ "first build of that version" — pin **builds**, not versions, in CI.

**ASM scan keys (what the generator should extract per anchor jar):**
1. Class presence (binary names) — the primary capability signal. Also inner classes (`DataComponentType$Valued`).
2. Method descriptors on a probe list (`ItemStack.setData(Lio/papermc/paper/datacomponent/DataComponentType$Valued;Ljava/lang/Object;)V`, `Entity.getRemovalReason()`, `Player.postEffects()`, `LivingEntity.setWaypointStyle(Lnet/kyori/adventure/key/Key;)V`, `Server.isPaused()Z`, `Entity.teleportAsync(...)` arity set).
3. `RuntimeInvisibleAnnotations` for `Lorg/jetbrains/annotations/ApiStatus$Experimental;`, `$Internal;`, `$Obsolete;`, `$ScheduledForRemoval;` (CLASS retention → not visible by reflection at runtime, only in bytecode) and `Ljava/lang/Deprecated;` + the `Deprecated` attribute (`forRemoval`/`since` live in the annotation element values).
4. Class kind flags (`ACC_INTERFACE`, `ACC_ENUM`): catches `Attribute` enum→interface (1.21→1.21.4) and the future `ItemStack` class→interface.
5. Static field sets on constant holders (`RegistryEvents`, `LifecycleEvents`, `MenuType`, `DataComponentTypes`, `Attribute`) — per-entry capabilities.
6. POM `dependencyManagement`: `adventure-bom`, `brigadier`, `jspecify` versions.
